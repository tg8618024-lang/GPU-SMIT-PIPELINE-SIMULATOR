Microarchitecture Reference & RTL Cheat Sheet

🏛️ 5-Stage Classic In-Order Pipeline

Stage Latches (Pipeline Registers)

  • IF/ID: Holds fetched instruction bits, PC+4
  • ID/EX: Holds decoded opcode, RegA, RegB, immediate, Rs1, Rs2, Rd, control signals
  • EX/MEM: Holds ALU output, Store Data, Rd, RegWrite, MemRead, MemWrite
  • MEM/WB: Holds Memory Read Data, ALU result, Rd, RegWrite

Forwarding (Bypass) Unit Equations

Forwarding bypasses data directly from later stages to the ALU inputs without waiting for Write-Back.

ForwardA = 2'b10 (EX/MEM → EX):
if (EX_MEM.RegWrite && EX_MEM.Rd != 0 && EX_MEM.Rd == ID_EX.Rs1)

ForwardA = 2'b01 (MEM/WB → EX):
if (MEM_WB.RegWrite && MEM_WB.Rd != 0 && MEM_WB.Rd == ID_EX.Rs1 && !(EX_MEM forwarding condition))

⚠️ Hazard Detection & Branch Prediction

Load-Use Data Hazard (Interlock)

When an instruction in ID reads a register loaded by a preceding LD in EX stage, a 1-cycle stall bubble is inserted:

if (ID_EX.MemRead && (ID_EX.Rd == IF_ID.Rs1 || ID_EX.Rd == IF_ID.Rs2)) {
  freeze(PC); freeze(IF_ID); injectBubble(ID_EX);
}

2-Bit Saturating Branch Predictor

Four-state Mealy FSM per branch target address:

00: Strongly Not Taken
01: Weakly Not Taken
10: Weakly Taken
11: Strongly Taken

Branches predict Taken if MSB = 1 (states 10 & 11). Mispredictions trigger a 1-cycle pipeline flush.

⚡ NVIDIA-Style GPU SM (SIMT) Microarchitecture

Register Scoreboard & Warp Scheduling

  • Scoreboard: 1-bit per register per warp. Set on instruction issue, cleared when writeback completes (ALU: 1 cyc, Load: 4 cyc).
  • Greedy-Then-Oldest (GTO): Gives priority to the oldest ready warp to minimize overall tail latency.
  • Round-Robin (RR): Rotates fairly between ready warps each clock cycle.

8-Bank Shared Memory Conflicts

Addresses map to banks: bank = (address >> 2) % 8.

When multiple active lanes in a warp request different addresses within the same bank, accesses are serialized:

Penalty Cycles = max_lanes_per_bank - 1
